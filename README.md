# First World

A small browser world-building prototype. Open index.html to play. No install or build needed. Drag to paint; keys 1–4 select tools. On the focused world, arrows move the brush and Space paints. Forests and mountains require land. Progress saves in browser storage. New world replaces the save after confirmation.

## GitHub Pages

Upload index.html, style.css, and game.js to a GitHub repository root. In the repository Settings → Pages, select Deploy from a branch, then main and / (root). GitHub provides the playable URL after deployment. No server or API keys are needed. The optional Google Fonts request falls back to system fonts offline.

This first chapter explores terrain and plants. Creatures and inhabitants are future chapters; the setting deliberately leaves room for future Earth or a fantasy world.
